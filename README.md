# Hasan Siddiqui — Portfolio

Source for my personal academic portfolio site, built with Jekyll and the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) remote theme, hosted on GitHub Pages.

**Live site:** [hssiddiqui.github.io/portfolio](https://hssiddiqui.github.io/portfolio)

I'm a PhD candidate in Mechanical Engineering at Columbia University working on geospatial data science, remote sensing, and machine learning for energy access in Sub-Saharan Africa. The site collects my research, publications, teaching, and side projects.

## Structure

- `_pages/` — site pages (Publications, Projects, Teaching, Resume)
- `assets/` — standalone interactive tools (e.g. the Betz optimum blade model, phenology mapping viewer) and images
- `_data/navigation.yml` — top navigation config
- `_config.yml` — site and theme settings

## Local development

```
bundle install
bundle exec jekyll serve
```
